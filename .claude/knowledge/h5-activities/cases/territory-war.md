# 陣營競賽：艾森諾攻防戰

- 上線時間：2024/09/18–10/06
- 機制類型：陣營競賽
- 原始目的：拉長活躍天數＋社交裂變
- 機制重點：
  - 上線前用連乘法保守估算任務達成率（登入60%×對戰75%×組隊40%×連殺30%……最終達成率會很低，這是常態不是設計失敗），從活躍玩家數反推陣營人數、每日資源產出、能攻下幾塊地
  - 後期機制刻意設計「互相牽制」：陣營互不相鄰時派兵直接消耗對方耐久，一旦接壤則雙方派兵互相抵消，製造後段戰局張力
  - 雙軌獎勵：個人里程碑（依累積代幣）＋團體排名獎勵（依陣營戰績），單兵貢獻與團隊勝負兩種誘因並存
  - 分享碼/邀請碼機制設每日上限（例如每人每天最多輸入3組、被輸入3次），防刷同時保留社交裂變
- 阻礙與解法（教訓）：活動上線後做「forecast vs actual」事後校準，該工單預熱繪券的預測與實際數據誤差僅 2.82%——這套「保守試算＋事後校準」流程本身是最值得延續的實踐，往後陣營競賽/數值型活動都該比照辦理
- 參與率／完成率：23.25% / 4.93%（門檻高、完成率天生很低，別用這類機制衝「完成率」類 KPI）
