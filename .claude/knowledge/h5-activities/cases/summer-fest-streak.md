# 多合一小遊戲＋連勝挑戰：夏日大闖關 Summer Fest、夏日酥脆挑戰賽

- 夏日大闖關：約6月；夏日酥脆挑戰賽：2025/06/14–06/30
- 機制類型：多合一小遊戲（反應操作：123木頭人/摳糖餅）＋連勝挑戰
- 原始目的：蹭熱門話題拉活躍（夏日大闖關工單原詞：結合六月夏日主題＋當下「Squid Game」熱點提升活躍）；夏日酥脆挑戰賽為單純節慶促活
- 機制重點：
  - 雙軌代幣（遊戲內任務＋小遊戲皆可獲得token）；小遊戲入口不消耗代幣，但每日遊玩次數有限
  - **連勝挑戰（push-your-luck 賭博機制）**：小遊戲過關後問玩家要「帶走目前確定拿到的代幣」還是「賭一把繼續挑戰更高連勝、拿更多代幣但失敗歸零」——讓簡單的基礎小遊戲多一層決策深度和刺激感，只需在結算流程加一個分支；每關連勝次數與代幣都設上限，玩家可隨時回主頁「提現」已確定代幣（提現後該關連勝挑戰結束不可反悔）
  - Serial code 全頁持續顯示，方便客服追蹤
- 阻礙與解法（教訓）：工單保留一整套「已棄用的舊版首頁設計」（入場券＋通關獎勵舊制）並標記 archived → 大改版是常態，工單留存舊方案紀錄供之後參考或重新採用，不是浪費
- 參與率／完成率：待補充
