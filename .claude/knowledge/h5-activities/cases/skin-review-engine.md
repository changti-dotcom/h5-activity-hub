# 劇情回顧引擎（Skin Review / Memories）：屬於我的2024傳說、週年慶回憶錄

- 屬於我的2024傳說：2024/07/05–07/08；週年慶回憶錄（8週年 Memories）：2024/10/25–10/28
- 機制類型：劇情回顧
- 原始目的：品牌口碑；工單原詞是 "for user engagement and defending purpose"——週年類活動除了口碑，還帶有「防止玩家對版本停滯的觀感」的防禦性動機
- 機制重點：
  - 個人化資料分兩軌：核心付費/活躍玩家（工單稱 A60）用專門資料池給豐富個人數據；其餘玩家用較簡單資料（勝場、擊殺、英雄/造型持有數）湊一頁
  - 用「稱號」包裝百分位數據（例如持有量前5%叫「收藏王者」），多重稱號條件都符合時高階蓋過低階
  - 敘事節奏可用「長按控制播放」：長按才淡入下一段文字/播放動畫，放開暫停，比純自動播放更拉長停留時間（8週年 Memories 工單稱之為水晶球場景轉場）
  - 高併發發獎走遊戲內信箱，畫面明講「預計24小時內發放完畢」
  - 分享頁單獨做「隱藏按鈕、只留數據」的乾淨截圖畫面
- 阻礙與解法（教訓）：工單自問「玩家太久沒登入、沒有足夠數據，還要不要給個人數據頁和獎勵？還是整個活動打不開？」→ 個人化回顧類活動一定要在企劃階段就設計好「無資料/資料不足」的兜底流程
- 參與率／完成率：屬於我的2024傳說 48.57% / 48.24%；週年慶回憶錄 43.97% / 27.48%
- 備註：這兩筆樣本的參與率與完成率都是所有機制裡最高、也最接近的（門檻是「看完」而非「玩過關」），適合衝品牌口碑，不適合衝需要長期操作的 KPI
