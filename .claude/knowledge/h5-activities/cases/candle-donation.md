# 捐獻排行榜／文化包裝：新年祈福光明燈

- 上線時間：2025/01/24–02/03
- 機制類型：捐獻排行榜／文化包裝
- 原始目的：節慶促活（工單 Event Type/Background 欄位留空未填，是推測）
- 機制重點：
  - 「一般燈」代幣來自遊戲內任務數據（有資料延遲，約1小時）、「特殊燈」代幣來自遊戲內即時 API 或邀請碼互動（即時判定）——混用兩種代幣來源的活動都該先問後端這兩種數據源的延遲特性
  - 若開放玩家直接用遊戲內真實貨幣（金幣）捐獻，因為要走遊戲內 API 會有延遲，需設節流機制（例如「每30分鐘僅可捐獻一次」）避免重複扣款
  - 用文化敘事包裝排行榜：「求籤」把任務完成度轉成籤詩「幸運值」直接當排行榜積分；捐獻最高者封為「爐主」；依捐獻等級給「大施主」類稱謂
  - 邀請機制刻意跟「好友流失天數」掛鉤：越久沒登入的好友，互相輸入邀請碼可得越多代幣，同時做到社交裂變和老玩家回歸召回
  - 里程碑要有完整「四態」視覺：未達標鎖住／已達標未到開放時間／已到時間未達標／已領取
  - 「一個框架、每天/每階段換一個小主題」延展思路：藥師燈/太歲燈/財神燈/平安燈/姻緣燈輪替撐起整檔活動新鮮感
- 阻礙與解法（教訓）：這份工單 Timeline 和 Data Request 段落完全空白→不是每份工單都完整，讀工單時要主動辨識「這份缺什麼」，不要預設所有工單都有齊全的規劃資訊
- 參與率／完成率：28.23% / 19.40%
- 備註：全期間累計消耗17億金幣，約全服金幣存量3%（貨幣沉澱型活動的特殊指標範例）
